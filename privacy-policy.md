## 🇨🇳 中文版

### 简介

感谢您使用"恢复已关闭标签页"扩展（以下简称"本扩展"）。我们重视您的隐私，本政策说明了我们如何处理您的数据。

### 我们收集什么信息

本扩展仅访问以下信息以提供核心功能：

- **浏览历史记录**：已关闭标签页的 URL、标题和关闭时间
- **用途**：显示最近关闭的标签页列表，允许您快速恢复

### 数据如何存储

- ✅ **完全本地存储**：所有数据仅保存在您的浏览器本地
- ✅ **不上传服务器**：我们没有任何服务器，不会上传您的数据
- ✅ **不与第三方共享**：不使用任何分析、广告或跟踪服务
- ✅ **不出售数据**：我们绝不会出售您的任何信息

### 数据安全

- 所有数据通过 Chrome 浏览器的本地存储 API 管理
- 您可以随时通过清除浏览器数据来删除所有信息
- 卸载扩展将自动删除所有相关数据

### 权限说明

本扩展请求的权限及用途：

| 权限       | 用途                        |
| ---------- | --------------------------- |
| `tabs`     | 获取标签页信息（URL、标题） |
| `sessions` | 访问最近关闭的标签页        |
| `storage`  | 保存用户设置（如显示数量）  |

### 您的权利

- 随时清除浏览历史记录
- 随时卸载扩展
- 在浏览器设置中管理扩展权限

### 儿童隐私

本扩展不会故意收集 13 岁以下儿童的信息。

### 政策更新

如有重大变更，我们会在扩展更新说明中通知您。

### 联系方式

如有任何问题，请通过以下方式联系：

- GitHub Issues: https://github.com/Teernage/recently-closed-tabs/issues
- GitHub Repository: https://github.com/Teernage/recently-closed-tabs

## 🇺🇸 English Version

### Introduction

Thank you for using the "Restore Closed Tabs" extension (the "Extension"). We value your privacy and this policy explains how we handle your data.

### What Information We Collect

This Extension only accesses the following information to provide core functionality:

- **Browsing History**: URLs, titles, and closing times of closed tabs
- **Purpose**: Display a list of recently closed tabs and allow quick restoration

### How Data Is Stored

- ✅ **Completely Local Storage**: All data is saved only in your browser locally
- ✅ **No Server Upload**: We have no servers and do not upload your data
- ✅ **No Third-Party Sharing**: No analytics, advertising, or tracking services used
- ✅ **No Data Sale**: We will never sell any of your information

### Data Security

- All data is managed through Chrome's local storage API
- You can delete all information at any time by clearing browser data
- Uninstalling the Extension will automatically remove all related data

### Permission Explanation

Permissions requested by this Extension and their purposes:

| Permission | Purpose                                     |
| ---------- | ------------------------------------------- |
| `tabs`     | Get tab information (URL, title)            |
| `sessions` | Access recently closed tabs                 |
| `storage`  | Save user preferences (e.g., display count) |

### Your Rights

- Clear browsing history at any time
- Uninstall the Extension at any time
- Manage Extension permissions in browser settings

### Children's Privacy

This Extension does not knowingly collect information from children under 13.

### Policy Updates

We will notify you of any significant changes in the Extension update notes.

### Contact

For any questions, please contact us:

- GitHub Issues: https://github.com/Teernage/recently-closed-tabs/issues
- GitHub Repository: https://github.com/Teernage/recently-closed-tabs
